# Anshul Jhajharia - Modern Portfolio Website

> **B.Tech ECE Student | AI & Technology Enthusiast**  
> JECRC University, Jaipur, India

A modern, high-performance, and responsive personal portfolio website built with React, Vite, Tailwind CSS, and Lucide Icons. Designed for seamless one-click deployment on **Vercel**.

---

## 🚀 Features

- **Hero Section**: Modern introduction with glowing animated accents, status badge, action CTAs, and code snippet preview.
- **About Me**: Student-friendly engineering narrative detailing interests in ECE, AI, web development, and digital productivity.
- **Education**: Detailed academic background at JECRC University with key coursework chips and learning areas.
- **Skills**: Interactive cards with proficiency meters and category filtering (HTML, CSS, JavaScript, Python, Artificial Intelligence, Generative AI, Web Development, Digital Productivity).
- **Projects**: Clean showcase cards with tech stack badges, highlight points, interactive modals, and GitHub links.
- **Achievements**: Filterable grid for Certifications, Hackathons, Courses, Awards, and an extensible template to easily add more.
- **Contact**: Direct contact cards (one-click copy email, LinkedIn, GitHub, Location) and a functional inquiry form.
- **Responsive Navigation**: Desktop sticky blurred navbar and animated mobile hamburger menu.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment Ready**: Optimized for [Vercel](https://vercel.com/)

---

## 💻 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```

---

## 🌐 Deploy to Vercel

1. Push this project to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Anshul's Portfolio"
   git remote add origin https://github.com/anshjhajhariacyb1/portfolio.git
   git push -u origin main
   ```
2. Log in to [Vercel](https://vercel.com).
3. Click **"Add New Project"** and import your repository.
4. Framework preset will automatically detect **Vite**.
5. Click **"Deploy"**!
